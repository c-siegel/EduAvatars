# Screenshots needed here

The `.svg` files in this folder are stand-ins, not real product screenshots. Before this repo
goes fully public, replace each one with a real PNG/JPEG of the running app (same filename, or
update the path in the README that links to it).

| File | Replace with a screenshot of... | Suggested size |
|---|---|---|
| `dashboard-overview.svg` | The dashboard's project list (`/dashboard`) — a few example projects/avatars. | 1280×800 |
| `configurator.svg` | The project Configurator wizard (`/dashboard/projects/:id/edit`), e.g. the Appearance or Behavior step. | 1280×800 |
| `public-chat.svg` | The public chat page (`/c/<slug>`) a visitor sees, with the 3D avatar and a short conversation. | 1280×800 |
| `analytics.svg` | The Analytics dashboard (`/dashboard/analytics`) showing example (non-sensitive!) usage stats. | 1280×800 |

Use a test/demo project for these — never a screenshot containing a real student's name, voice
recording, or conversation content.
